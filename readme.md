# ChargeFlow 充电流

县区级智能充电寻桩与补能预警系统。

## 项目简介

ChargeFlow 面向新能源汽车用户，综合考虑车辆剩余电量、目标电量、充电站位置、预计行驶时间、等待时间和充电成本，为用户推荐合适的充电站。

## 当前功能

- 充电站候选排序
- 车辆电量与补能需求模拟
- 路线规划与行驶时间估算
- 充电等待时间和费用估算
- 充电站空间分布可视化

## 技术栈

- Python
- Streamlit
- Folium
- OpenStreetMap / OSRM

## 开发计划

当前版本用于原型验证，车辆状态和充电站数据仍需进一步接入真实数据。

后续将完善真实充电站数据导入、路线时间成本计算、充电兼容性检查与补能预警。

## 运行方法

安装依赖后运行：

```bash
python -m streamlit run app.py
```

本项目仍在开发中，推荐结果仅供演示与测试使用。
